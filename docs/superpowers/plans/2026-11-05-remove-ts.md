# Remove the TS app and make the Go app the repository root

Date: 2026-11-05. Branch `chore/remove-ts` from `master` at `1dc7ab7` (PR #16 merged). The Go app serves production (`www.neofox.dev`, `translate.jers.dev`); the TS Vercel project is deleted. User decisions: stop using TS; remove its code after #16; then move the Go app out of `go/` to the repository root.

## Goal

One app, written in Go, at the repository root. No TS application code, no TS-vs-Go parity machinery, no legacy paths. Every tool that keeps value (quality evals, golden request bodies, e2e suite, perf harness, CI) runs against the Go app. Behaviour and markup of the deployed app do not change.

## Order of work (each step leaves the repo green)

1. **Decouple Go from TS sources** (still in `go/`): stylesheet source moves into Go; golden fixtures regenerate from Go (`-update`), byte-identical to today's; drop `TestPrimitivesMatchReact`/`react-markup.json`; freeze the learning corpus. `go test`, `make check` pass.
2. **Evals on Go**: `cmd/request` + provider rewrite; run `npm run eval:ci` against the cache only (no new billed calls: the request bodies are byte-identical, so every cached translation hits). If a cache miss would bill, stop and ask.
3. **Delete TS**: `src/`, TS configs, `tests/browser`, TS scripts, TS deps; e2e/perf/visual lose their TS branches; `package.json`/lock updated.
4. **Move Go to the root**: `git mv go/* .` (Go module at root, `embed` reads `shared/translation` directly, drop `syncshared`); fix every path (Makefile, CI, e2e webServer, mise.toml, `.gitignore`, docs).
5. **Docs**: `AGENTS.md`, `README.md`.
6. **Verify**: `go test ./...`, `node --test`, eval cache run, e2e per tag one at a time (2 workers; the machine crashed on full runs), visual baselines written once from this branch and compared. Vercel: reset root directory, push, preview Ready, smoke the preview (1 billed). Open the PR.

## Not in scope

No behaviour, markup or prompt changes. The historical reports and plans under `docs/superpowers` stay as they are (they describe the migration).
